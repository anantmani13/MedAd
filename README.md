# CureBot - AI-Powered Medicine Recommendation System

🏥 **CureBot** is an intelligent medicine recommendation system powered by Machine Learning and Google AI.

## 🚀 Features
- 🤖 **Hybrid ML Model**: TF-IDF + Semantic Search (Sentence Transformers)
- 💊 **Massive Database**: 248,000+ medicines with real-time search
- 🧠 **60+ Diseases**: Cancer, Heart, Diabetes, COVID, and more
- 📊 **ML Disease Analytics**: Real-time prevalence & severity calculation
- 🎤 **Voice Input**: Speech-to-Text (Hindi & English support)
- 🌐 **Google Translate**: Hindi to English via Gemini AI
- 🤖 **Gemini AI**: Intelligent health advice and recommendations
- 🚨 **Emergency Mode**: Instant hospital locator
- 🗺️ **Pharmacy Finder**: OpenStreetMap integration for nearby pharmacies
- 🎨 **Modern UI**: 25+ animations, glass morphism effects

## 🧠 ML Technologies
- **TF-IDF Vectorization**: 15K features, n-grams 1-4, sublinear scaling
- **Cosine Similarity**: Accurate medicine matching algorithm
- **Semantic Search**: Sentence Transformers (all-MiniLM-L6-v2)
- **Hybrid Ranking**: Combines keyword + meaning-based search
- **ML Analytics**: Dynamic prevalence calculation from 248K database
- **Smart Filtering**: Body-part detection & symptom mapping

## 🎯 Google Technologies Used
| Technology | Purpose |
|------------|---------|
| **Gemini 2.0 Flash API** | Health advice & medical recommendations |
| **Gemini AI Translation** | Hindi to English translation |
| **Web Speech API** | Browser-based voice input |
| **OpenStreetMap** | Free pharmacy location mapping |

## 📊 Tech Stack
- **Framework**: Python Dash (port 7860)
- **ML Libraries**: scikit-learn, sentence-transformers
- **AI**: Google Gemini API
- **Visualization**: Plotly graphs
- **Maps**: Leaflet.js + OpenStreetMap
- **Data**: Pandas (298K+ records)

## 📈 Database Scale
- Dataset 1: 248,218 medicines
- Dataset 2: 50,000 inventory items
- Disease Categories: 60+ supported
- Symptom Categories: 30 with synonyms
